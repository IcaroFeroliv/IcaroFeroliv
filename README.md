## 🚀 Projetos em Destaque

### 🔧 Ferramentas BIM / CAD

#### [ClashWorks](https://github.com/IcaroFeroliv/ClashWorks) ⭐
Plugin para **Autodesk Revit** que lê relatórios HTML exportados do Navisworks e cria um painel interativo dentro do Revit. Com um clique, os elementos em conflito são localizados, isolados e exibidos em uma vista 3D com Section Box.
- Mapeamento dinâmico de colunas do relatório, mesmo exportado em ordens diferentes
- Suporte a grupos e comentários do coordenador BIM
- Memória de sessão em `.json`: clashes resolvidos continuam resolvidos após reiniciar o Revit
- **Stack:** C#, Revit API, WPF, HtmlAgilityPack, Newtonsoft.Json

#### [NavisworksClashUpdater](https://github.com/IcaroFeroliv/NavisworksClashUpdater)
Plugin para **Navisworks Manage** que atualiza em lote o status dos clashes (*Reviewed* / *Approved*) do Clash Detective a partir de um arquivo JSON.
- Suporte a Navisworks **2022 e 2027**, com uma branch por versão da API
- Ignora clashes já resolvidos para preservar o histórico
- **Stack:** C#, .NET Framework 4.8, Navisworks API

#### [Extrair_Tabela_AutoCAD](https://github.com/IcaroFeroliv/Extrair_Tabela_AutoCAD)
Plugin para **AutoCAD** que extrai tabelas de detalhamento de armaduras (aço) direto do DWG nativo para planilhas Excel (`.xlsx`) formatadas, sem depender de OCR.
- Agrupamento espacial dos textos (`DBText` e `MText`) e leitura de nomenclaturas complexas (`BA4`, `BM1`, `B3=B5=B11`)
- Exportação em abas separadas (Pilares, Vigas, Blocos, Cintas) com formatação profissional
- **Stack:** C#, .NET Framework 4.8, AutoCAD API, EPPlus

#### [Plugin_Revit_Tutorial.NET8](https://github.com/IcaroFeroliv/Plugin_Revit_Tutorial.NET8)
Guia passo a passo, com código-fonte base, para criar o **primeiro plugin no Revit 2025+** usando C# e .NET 8.0: configuração do projeto, referências da API, debug, post-build, manifesto `.addin` e um "Hello World".
- **Stack:** C#, .NET 8, Revit API, WPF

> 💼 Também desenvolvo plugins comerciais e internos (como o **ARQ Flow**) para automação e compatibilização em Revit e Navisworks.

### 🌐 Sistemas Web

#### [GiroCarERP](https://github.com/IcaroFeroliv/GiroCarERP)
Sistema web para gestão de uma revenda de veículos: estoque, vendas, pagamentos, manutenções, clientes, fornecedores, lojas e funcionários, com consulta à **Tabela FIPE**. Projeto acadêmico em equipe (Gestão e Qualidade de Software), com testes automatizados das regras de negócio.
- **Stack:** Python, Streamlit, Supabase (PostgreSQL), Pandas, Pytest

#### [GotaSix](https://github.com/IcaroFeroliv/GotaSix)
Plataforma full-stack para monitoramento do consumo de água residencial e comercial. O usuário registra leituras do hidrômetro, acompanha o gasto em gráficos e recebe alertas de possíveis vazamentos, com base na meta de 110 L/dia por pessoa recomendada pela OMS.
- Gráficos de linha desenhados nativamente em SVG no Blazor
- Senhas com hash BCrypt e preenchimento de endereço via API ViaCEP
- **Stack:** Blazor WebAssembly, ASP.NET Core Web API, SQLite, Entity Framework Core
